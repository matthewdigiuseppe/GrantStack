# Ethics

`/draft-section ethics` drafts this. ERC runs a formal ethics self-assessment
and may flag a proposal for ethics review; NWO requires an ethics statement
where relevant. Get this right — an unresolved ethics flag can block an
otherwise-funded grant.

Cover, where applicable:

- Human participants (consent, vulnerable groups, recruitment).
- Personal data / GDPR.
- Animals.
- Non-EU / dual-use / environmental concerns.
- Approvals already held or to be obtained, and from whom.

If nothing applies, say so explicitly per category rather than leaving blanks.
